Về Game Ninja

Khám phá bộ sưu tập 2 game Ninja Java cổ điển tuyệt vời nhất. Tất cả đều được tối ưu để chơi miễn phí ngay trên trình duyệt web của bạn, không cần tải về hay cài đặt.

Đây là những tựa game Ninja kinh điển từ thời kỳ hoàng kim của Java Mobile, đã gắn liền với tuổi thơ của hàng triệu game thủ Việt Nam. Bạn có thể chơi ngay trên máy tính, laptop hoặc điện thoại thông minh.
